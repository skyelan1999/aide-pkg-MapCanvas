# 栅图 MapCanvas

Aide 公用 ROS 栅格地图编辑工作台。插件 ID：`mapcanvas`，当前版本：`0.2.0`，MIT。

从 YAML + PGM/PNG 地图开始，浏览、缩放、平移、画墙或擦墙；支持灰色未知区域画笔、笔刷预览、撤销、重做及导出配套地图 ZIP。“浏览 / 上级”右侧可收起路径列表，保留当前目录与结果。可写来源的原图片通过 Aide 上方的“保存到原文件”按钮确认后保存。YAML 分辨率、原点、阈值和 posegraph 不随原图保存改动。

## 安装前提

需要包含 `map-image-document-v1` 和 `plugin-tool-images-v1` 能力的 Aide 主程序源码构建（宿主集成提交见本版 Release）。旧版 0.1.18.0 RC3 安装包本身不包含本次宿主增量；市场会通过能力要求拒绝不兼容的宿主。不要只看相同版本字符串判断能力已存在。

本插件是 JavaScript + HTML，不需要在用户机器上运行 npm 或编译。ZIP 安装包不包含宿主程序，也不会自行修改 Aide。平台标签表示可安装的 Node/浏览器目标，不代表完成了全部操作系统的实机验收。

## 使用

1. 从 Aide 插件市场安装并启用 **栅图 MapCanvas**，打开工作台。原有 `ros-map-editor` 使用不同 ID，原插件不会被覆盖或卸载。
2. 选择工作目录或已经授权可见的文件来源，点“浏览”选择 `.yaml`。图片栏默认根据 YAML 的 `image` 字段解析同来源路径；必要时手动指定。
3. 点“导入”，选画墙、擦墙或手形。滚轮缩放，空格或中键临时平移；使用适应、1:1、撤销和重做检查编辑。
4. 可写来源：点软盘准备原图草稿，再点 **Aide 宿主上方“保存到原文件”**；看到保存成功前不算落盘。外部文件被更改、来源撤销/只读、切换工作区或锁屏时拒绝旧草稿。
5. 只读来源或本机文件选择器导入：使用“导出 ZIP”，再点宿主的“保存文件”下载。原来源不被覆盖。示例 `examples/map.yaml` 和 `examples/map.pgm` 可复制到测试目录熟悉操作。
6. 保存超时或状态不明时先核对文件，不自动重复保存；“取消待保存”保留画布编辑。

## Aide 预览与操作接口

启用插件后，工具描述直接进入 Aide 的工具列表。调用 `mapcanvas_help` 获取完整 [AI 工具指南及提示词](AI-GUIDE.md)；工作台也有“AI工具指南”按钮。

- `mapcanvas_preview`：从授权来源读取 YAML＋PGM/PNG，返回真实 PNG 视觉证据、像素坐标映射和图像/YAML摘要；可裁剪，也可带操作只读试画。
- `mapcanvas_edit`：以两项摘要核对输入，执行画墙/擦墙/灰色的笔画或矩形，生成派生 PGM＋YAML 两条文件提案。复用 Aide 文件应用流程，收到实际回执后预览输出 YAML 复核。原图和未保存画布不会被工具直接替换。
- `mapcanvas_sources` / `mapcanvas_browse` / `mapcanvas_read`：来源枚举、路径浏览及低层分块读取。新的预览/编辑使用 `sourceId`，低层接口保持 `source` 兼容。

提示词示例：“使用 MapCanvas 预览 maps/map.yaml，把原图像素 x=10、y=5、宽4、高8的矩形标为灰色未知区域；先试画，再生成 exports/map-edited.pgm 和配套 YAML 的提案，应用后读回复核。”

工具像素原点在左上，x向右、y向下；不把缩略图像素或米当作原图坐标。灰色值按 negate 和 free/occupied 阈值计算，支持16位PGM。AI PNG 输入要求非交错8位灰度；派生PGM为可读P2文本，后续GUI原图保存仍为P5。单次128操作、4096点、32百万估算像素工作量，P2文本最多24MiB。

## 格式与边界

- 标准单文档 ROS 地图 YAML，最多 64 KiB；支持 trinary。不是通用 YAML 编辑器。
- PGM 支持 P2/P5，最大灰度 65535，限制 4,194,304 像素；拒绝畸形数字、像素溢出和不匹配的栅格长度。
- PNG 支持 8 位不透明灰度图；图片最多 8 MiB、4,194,304 像素。浏览器解码后验证灰度和透明度。
- 原图保存保留 PNG/PGM 格式和尺寸；PGM 写为 P5，不保留原 P2 排版或注释。PNG 不承诺保留非地图元数据。ZIP 另存为 YAML + PGM。
- 不修改定位图、posegraph，不连接机器人、不发送导航目标或运动控制。
- 来源读权限不等于写权限。文件读取与暂存通过 Aide 的可见来源 API；原图覆盖复用文档版本与原子替换通道，不扩大其他插件的来源权限。

## 开发与验证

`npm test` 运行实际页面解析/编码函数与入口工具测试；`npm run package` 构建固定文件白名单、固定时间戳的 ZIP 及 SHA256SUMS。发布包不含实例设置、用户地图、宿主补丁、测试数据缓存或凭据。

本版由用户提供的 ROS 地图编辑器 0.4.7 有效源码整理、改名并修正 P2 像素整数溢出；保留原版本作独立插件。Aide 宿主增量在 `skyelan1999/aide`，插件源码在 `skyelan1999/aide-pkg-MapCanvas`，集中问题跟踪在 Aide 主仓库。具体安装、页面与保护用例的结果见 [验收记录](https://github.com/skyelan1999/aide-pkg-MapCanvas/blob/main/docs/ACCEPTANCE.md)。
