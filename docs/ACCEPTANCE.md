# MapCanvas 0.2.1 验收记录

## 变更

未知画笔在导入时统计原图像素，沿用出现最多且在YAML的negate/free/occupied阈值之间的未知灰度；同票按灰度升序确定，绘图期间固定该值。还验证转换为8位后仍为未知。没有未知像素时明确显示回退值，无法表达则禁用灰笔而不阻碍二值地图导入。GUI与AI共用核心，预览返回unknownBrush的value/source/count。

界面统一线性SVG图标、分组工具、来源卡片、画布边界与低对比网点、灰度色样与未保存标记，跟随Aide明暗主题。工具区域空间不足时独立滚动，保留画布；路径列表仍可收起。本机文件选择只在勾选时显示。

## 本地实际验收

沿用localhost:9999及既有aide-aide-1，没有另开Aide或容器。当前本地插件升级启用0.2.1，保留原版与升级备份。

- 16项Node测试通过：新增原灰128/205/16位、negate、无未知色回退、无法在Nav2的8位精度表达的拒绝、选值冻结与输入不变；实际AI预览/试画/配套PGM提案均继承128。
- 通过现有容器运行宿主候选ZIP回归：真实安装、工具分发、PNG证据、提案、应用读回、过期摘要拒绝。宿主用例区分旧0.2.0中点147和新版本继承原样本127，向后兼容。
- 原生界面导入80×60合成地图，显示“原图未知灰度128/255”；手动涂抹、撤销、重做与宿主确认保存通过。64个变化像素全部为128，没有140或147；YAML未修改。
